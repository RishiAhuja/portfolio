A comprehensive e-scooter sharing platform integrating IoT hardware with a modern Flutter application for seamless urban mobility.

## IoT Integration

SahlPlus connects directly with e-scooter hardware, providing real-time location tracking, battery monitoring, and remote lock/unlock functionality through IoT device integration.

## Platform Features

### Smart Fleet Management
- Real-time GPS tracking of all vehicles
- Battery status monitoring
- Remote vehicle control system

### User Experience
- Secure payment gateway integration
- Performance-optimized with lazy loading
- Clean architecture with Riverpod state management

## Backend Infrastructure

Robust backend built with Go, containerized with Docker for reliable, scalable deployment. RESTful API design ensures smooth cross-platform functionality.
