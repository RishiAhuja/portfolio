An intelligent PDF querying system that transforms how you interact with documents through AI-powered analysis and smart recommendations.

## Achievement

🥉 2nd Runner-up at IEEE PEC Hack - Built in under 18 hours!

## Key Features

### Intelligent Querying
- Natural language questions about PDF content
- AI-powered context understanding with Gemini AI
- Smart answer extraction with source citations

### Document Analysis
- Multi-document support
- Citation tracking across sources
- Recommendation engine for related content

## Technology

Built with Flutter for cross-platform support, leveraging Syncfusion for PDF rendering and Firebase for cloud storage. Powered by Gemini AI for intelligent document understanding and query processing.
